🌍 Wanderlust – MERN Stack Full-Stack Web Application

Wanderlust is a full-stack web application inspired by Airbnb, developed using the MERN stack.
The platform allows users to explore travel destinations, view detailed property listings, and manage listings through a secure authentication system.

📌 Project Overview

This project demonstrates the implementation of:

RESTful APIs

Secure user authentication

Cloud-based database integration

Dynamic server-side rendering

MVC architecture

It is designed as a scalable and maintainable web application following industry best practices.

🚀 Features

🏠 Browse and explore property listings

🔍 Search destinations

👤 User authentication (Sign Up / Login / Logout)

🏡 Create, edit, and delete property listings

🖼 Image upload and management

🌐 MongoDB Atlas cloud database

📱 Responsive and user-friendly UI
